# Usage & Requirements

## Interactive Mode

Launch the main dashboard:

```bash
devcli
```

*   **Arrow Keys**: Navigate
*   **Enter**: Select
*   **Esc / Q**: Back / Exit

## Direct Subcommands

Access specific features directly:

```bash
devcli dev          # Open project management tools
devcli file         # Launch file manager
devcli ai           # Start AI chat session
devcli editor FILE  # Open file in built-in editor
```

## Keyboard Shortcuts

### Global Navigation
*   `Arrow Up/Down`: Navigate
*   `Enter`: Confirm/Execute
*   `Esc` or `Q`: Return/Exit
*   `Ctrl+C`: Force quit

### Feature-Specific

**Project Tools**:
*   `B`: Backup project
*   `D`: Delete history
*   `?`: Help

**Virtual Environment Wizard**:
*   `N`: New environment
*   `S`: Scan workspace
*   `Y`: Sync requirements.txt
*   `C`: Clone environment
*   `D`: Delete environment

**Dev Server**:
*   `S`: Start/Stop
*   `F`: Toggle filters
*   `/`: Search logs
*   `A`: Toggle auto-scroll
*   `C`: Clear logs

**File Manager**:
*   `C`: Copy
*   `M`: Move/Rename
*   `D`: Delete
*   `E`: Edit
*   `N`: New file
*   `H`: Toggle hidden files

**Editor**:
*   `Ctrl+R`: Run code
*   `Ctrl+S`: Save
*   `Ctrl+N`: New file
*   `Ctrl+H`: Help
*   `Ctrl+C`: Exit editor

**Docs**:
*   `L`: Cycle languages
*   `Arrow Keys`: Scroll
